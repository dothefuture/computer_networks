# Домашнее задание №10

Отдельного письменного ДЗ по DHCP не выдавали. В репозитории лежит конспект по презентации «DHCP короткий».

[Конспект: протокол DHCP](../class/Протокол%20DHCP.md)

Кратко по сути занятия:

- DHCP автоматически выдаёт IP, маску, шлюз и DNS;
- режимы: ручные статические адреса, автоматические статические, динамическая аренда;
- обмен: Discover → Offer → Request → ACK;
- при сервере в другой подсети используется DHCP relay.
