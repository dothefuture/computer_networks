## Решение задач по расчету IP-сетей и подсетей

### Задача №1

#### Условие

Разделить исходную сеть 192.168.1.0/24 на 4 равные подсети

#### Пошаговое решение
   1. Заимствование бит для подсетей: Чтобы получить 4 подсети, используем формулу $2^n = 4$, где $n$ - количество занимаемых бит. Отсюда $n = 2$.
   2. Расчет новой маски: Добавляем 2 бита к маске: $24 + 2 = 26$. Новая маска - /26.В десятичном: $128 + 64 = 192$. Итоговая маска: 255.255.255.192.
   3. Определение шага и емкости хостов:
   * Шаг подсетей: $2^{(32-26)} = 2^6 = 64$ адреса.
      * Количество рабочих хостов: $64 - 2 = 62$ (минус адрес сети и broadcast).

#### Результаты расчета

* Маска подсетей: 255.255.255.192 (/26)
* Доступно узлов в каждой подсети: 62

| № подсети | Адрес сети       | Диапазон полезных адресов      | Широковещательный адрес |
| --------- | ---------------- | ------------------------------ | ----------------------- |
| Подсеть 1 | 192.168.1.0/26   | 192.168.1.1 - 192.168.1.62     | 192.168.1.63            |
| Подсеть 2 | 192.168.1.64/26  | 192.168.1.65 - 192.168.1.126   | 192.168.1.127           |
| Подсеть 3 | 192.168.1.128/26 | 192.168.1.129 - 192.168.1.190  | 192.168.1.191           |
| Подсеть 4 | 192.168.1.192/26 | 192.168.1.193 - 192.168.1.254  | 192.168.1.255           |

### Задача №2

#### Условие

Для исходной сети 192.168.10.0/24 определить маску и количество получившихся подсетей при условии выделения 50 хостов на каждую.

#### Пошаговое решение

   1. Расчет размера блока для 50 хостов: С учетом 2 служебных адресов требуется минимум $50 + 2 = 52$ адреса. Ближайшая большая степень двойки - $2^6 = 64$. Для адресации хостов нужно оставить 6 бит.
   2. Расчет новой маски: Длина маски: $32 - 6 = 26$ бит. Маска подсети - /26 (255.255.255.192).
   3. Количество подсетей:
    * Было заимствовано 2 бита ($26 - 24 = 2$).
        * Количество подсетей: $2^2 = 4$.

#### Результаты расчета

* Искомая маска: 255.255.255.192 (/26)
* Количество подсетей: 4

| № подсети | Адрес сети        | Диапазон полезных адресов        | Широковещательный адрес |
| --------- | ----------------- | -------------------------------- | ----------------------- |
| Подсеть 1 | 192.168.10.0/26   | 192.168.10.1 - 192.168.10.62     | 192.168.10.63           |
| Подсеть 2 | 192.168.10.64/26  | 192.168.10.65 - 192.168.10.126   | 192.168.10.127          |
| Подсеть 3 | 192.168.10.128/26 | 192.168.10.129 - 192.168.10.190  | 192.168.10.191          |
| Подсеть 4 | 192.168.10.192/26 | 192.168.10.193 -  192.168.10.254 | 192.168.10.255          |

### Задача № 3

#### Условие
Разделить исходную сеть 192.168.100.0/24 на 3 равные подсети

#### Пошаговое решение

   1. Ограничение двоичной логики: Разделить адресное пространство ровно на 3 равные части без остатка невозможно, так как количество подсетей всегда кратно степени двойки.
   2. Выбор схемы деления: Сеть делится на ближайшее большее число подсетей - 4 части. При этом 3 подсети отдаются под рабочие нужды, а 4 остается в резерв).
   3. Параметры деления:  Маска сдвигается на 2 бита: с /24 до /26 (255.255.255.192). Шаг подсетей составляет 64 адреса.

#### Результаты расчета

* Маска подсетей: 255.255.255.192 (/26)
* Количество используемых подсетей: 3 (1 в резерве)

| Статус подсети           | Адрес сети         | Диапазон полезных адресов         | Широковещательный адрес |
| ------------------------ | ------------------ | --------------------------------- | ----------------------- |
| Подсеть 1 (Используется) | 192.168.100.0/26   | 192.168.100.1 - 192.168.100.62    | 192.168.100.63          |
| Подсеть 2 (Используется) | 192.168.100.64/26  | 192.168.100.65 - 192.168.100.126  | 192.168.100.127         |
| Подсеть 3 (Используется) | 192.168.100.128/26 | 192.168.100.129 - 192.168.100.190 | 192.168.100.191         |
| Подсеть 4 (В резерве)    | 192.168.100.192/26 | 192.168.100.193 - 192.168.100.254 | 192.168.100.255         |

### Распределение резервной подсети на 8 подсетей

#### Пошаговое решение

   1. Резервная подсеть имеет адрес 192.168.100.192/26.
   2. Заимствование бит для 8 подсетей: используем формулу $2^n = 8$. Отсюда n = 3.
   3. Расчет новой маски: Добавляем 3 бита к текущей маске: 26 + 3 = 29. Новая маска - /29. В десятичном: 128 + 64 + 32 + 16 + 8 = 248. Итоговая маска: 255.255.255.248.
   4. Определение шага и емкости хостов:
   * Шаг подсетей: $2^{(32-29)} = 2^3 = 8$ адресов.
      * Количество рабочих хостов в каждой новой подсети: 8 - 2 = 6 устройств.
