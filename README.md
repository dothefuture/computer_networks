## Где лежат файлы

- `classwork/lesson_XX` содержит конспекты классных работ, `classwork/notes` — дополнительные заметки;
- `homework/lesson_XX` содержит домашние работы;
- `tests` содержит проверочные работы;
- `exam` содержит экзаменационную работу;
- `.github/assets` содержит изображения и схемы;
- `.github/pkt` содержит проекты Cisco Packet Tracer.
