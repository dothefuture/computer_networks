# Проверочная работа №1

## Часть A. Теория

1. **Что такое компьютерная сеть?**
   Это группа связанных устройств, которые обмениваются данными и могут использовать общие ресурсы.

2. **Основные топологии:** звезда, кольцо, шина, дерево и ячеистая топология.

3. **Чем LAN отличается от WAN?**
   LAN работает на небольшой территории, например в квартире, офисе или здании. WAN связывает сети на больших расстояниях.

4. **Уровни OSI снизу вверх:** физический, канальный, сетевой, транспортный, сеансовый, представления, прикладной.

5. Коммутатор обычно работает на канальном уровне, маршрутизатор на сетевом.

6. **Уровни TCP/IP:** сетевой доступ, межсетевой, транспортный, прикладной.

7. **Соответствие моделей:** уровни OSI 1 и 2 соответствуют сетевому доступу TCP/IP, уровень 3 межсетевому, уровень 4 транспортному, уровни 5, 6 и 7 прикладному.

8. Надёжную доставку с установлением соединения обеспечивает TCP.

9. Быструю передачу без гарантии доставки обеспечивает UDP.

10. MAC-адрес идентифицирует сетевой интерфейс и используется на канальном уровне OSI.

11. MAC-адрес занимает 48 бит, то есть 6 байт. Пример записи: `00:1A:2B:3C:4D:5E`.

## Часть B. IPv4

12. `192.168.10.130` в двоичном виде: `11000000.10101000.00001010.10000010`.

13. Адрес `172.16.5.10` относится к классу B, так как первый октет находится в диапазоне от 128 до 191.

14. `192.168.1.1` является частным адресом. Он входит в диапазон `192.168.0.0/16`.

15. Для `192.168.1.0/24`: маска `255.255.255.0`, доступно 254 адреса устройств, адрес сети `192.168.1.0`, broadcast `192.168.1.255`.

16. В сети `10.0.0.0/30` всего 4 адреса, для устройств доступны 2.

17. Шлюз по умолчанию принимает пакеты, для которых устройство не знает отдельного маршрута. Обычно это адрес маршрутизатора в локальной сети.

## Часть C. MAC-адреса

18. Записи `00:1A:2B:3C:4D:5E`, `00-1A-2B-3C-4D-5E` и `001A.2B3C.4D5E` корректны. В четвёртой записи не хватает одного байта, в пятой байт лишний, а в шестой есть символ `G`, которого нет в шестнадцатеричной системе.

19. Для `A4:5E:60:12:34:56`: OUI равен `A4:5E:60`, NIC равен `12:34:56`. Младший бит первого байта равен нулю, поэтому адрес unicast.

20. Широковещательный MAC-адрес: `FF:FF:FF:FF:FF:FF`. Кадр с таким адресом получают все устройства в широковещательном домене.

21. MAC относится к канальному уровню, обычно постоянен для интерфейса и занимает 48 бит. IPv4 относится к сетевому уровню, назначается в конкретной сети и занимает 32 бита.

22. Коммутатор запоминает MAC-адрес источника и порт, с которого пришёл кадр. Эти записи образуют MAC-таблицу. По ней коммутатор выбирает порт для отправки кадра. Если адрес назначения ещё неизвестен, кадр отправляется через все подходящие порты, кроме входного.

## Часть D. Маршрутизация

23. Маршрутизация нужна для выбора пути между сетями. Маршрутизатор проверяет IP-адрес назначения, выбирает маршрут и пересылает пакет дальше.

24. Таблица маршрутизации содержит сеть назначения, маску или префикс, следующий узел, выходной интерфейс и метрику.

25. Пакет для `192.168.1.55` уйдёт через `Fa0/0`, для `10.5.5.5` через `Fa0/1`, для `8.8.8.8` через маршрут по умолчанию `Fa0/2`.

26. При совпадении нескольких маршрутов выбирается маршрут с самым длинным префиксом. Он точнее остальных описывает сеть назначения.

27. Статический маршрут администратор задаёт вручную. Динамические маршруты строятся и обновляются с помощью протокола маршрутизации, например RIP или OSPF.

## Часть E. Практика

28. Для 500 устройств нужно 9 бит под адреса хостов: `2^9 - 2 = 510`. Новый префикс `/23`, маска `255.255.254.0`. Из исходной сети `/16` получится 128 подсетей. Первая подсеть: адрес сети `172.16.0.0`, первый хост `172.16.0.1`, последний хост `172.16.1.254`, broadcast `172.16.1.255`.

29. Сначала приложение формирует HTTP-запрос. Если используется доменное имя, перед этим DNS помогает узнать IP-адрес сервера. На транспортном уровне TCP устанавливает соединение и добавляет номера портов. На сетевом уровне IP добавляет адреса отправителя и сервера. На канальном уровне создаётся кадр с MAC-адресами текущего участка сети, после чего физический уровень передаёт биты. Маршрутизаторы меняют канальный заголовок для каждого следующего участка, но IP-адрес назначения остаётся адресом сервера. На сервере заголовки снимаются в обратном порядке, и HTTP-запрос попадает нужному приложению.
